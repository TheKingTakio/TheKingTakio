# La Ñapa — Domicilios de barrio

PWA de domicilios para Soacha (El Danubio, Hogares Soacha, Prado Vega y Ciudad Verde).
React + Vite + TypeScript + Tailwind + Supabase. Diseño en `DESIGN.md`.

## Comandos
- `npm install` — instalar
- `npm run dev` — probar en tu computador
- `npm run build` — compilar para publicar
- `node scripts/generar-iconos.mjs` — regenerar íconos (usa `logo-512.png`, `logo-192.png` y `logo-32.png` de la raíz si existen)
